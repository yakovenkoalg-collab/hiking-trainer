# Использование данных здоровья

«Горная форма» читает данные Health Connect только после явного разрешения пользователя:

- тренировки;
- пульс;
- сон;
- шаги;
- расстояние;
- набор высоты;
- вес.

Данные используются для личного плана, сводок и защиты от двойного учёта нагрузки. По умолчанию они хранятся только в локальной базе приложения. Пользователь может явно выбрать общую папку через системный Android-проводник и отдельно включить автообмен. В этом случае отчёт передаётся выбранному им облачному провайдеру. Фото осанки в обмен не включаются.

Пользователь может отозвать разрешения в настройках Health Connect, отключить автообмен или отозвать доступ к общей папке в системных настройках Android.
