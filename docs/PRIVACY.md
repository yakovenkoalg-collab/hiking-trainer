# Использование данных здоровья

«Горная форма» читает данные Health Connect только после явного разрешения пользователя:

- тренировки;
- пульс;
- сон;
- шаги;
- расстояние;
- набор высоты;
- вес.

Данные используются для личного плана, недельных сводок и защиты от двойного учёта нагрузки. Они хранятся в локальной базе приложения и не отправляются автоматически на сервер или третьим лицам.

Пользователь может отозвать разрешения в настройках Health Connect. Экспорт отчёта выполняется только по явному действию пользователя и не содержит фотографий.
