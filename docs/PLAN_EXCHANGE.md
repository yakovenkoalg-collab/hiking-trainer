# Формат совместной корректировки

## Отчёт

Файл `*.mountain-report.json` содержит версию схемы, период, агрегированные показатели, тренировки, readiness, наблюдения боли, метрики тела, цели и текущие ограничения.

Отчёт не включает фотографии и не отправляется автоматически.

## План

Файл `*.mountain-plan.json` содержит полную версию будущих тренировок, причину изменений и ожидаемый период действия.

## Безопасный импорт

1. Проверить версию схемы и обязательные поля.
2. Отклонить конфликтующие идентификаторы.
3. Сопоставить упражнения с активными ограничениями.
4. Показать preview «было / станет».
5. Применить только после явного подтверждения.
6. Сохранить предыдущую ревизию для отката.
