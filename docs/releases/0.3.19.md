## Как считается сверка с пульсом

Приложение хранит круги и пульсовые зоны записи, а не каждую секунду, поэтому время выше границы — оценка по кругам: круг считается «выше», если его средний пульс выше границы. Отдельно показывается нижняя оценка по зонам часов — время в зонах, которые целиком лежат выше границы. Если кругов нет, сравнивается средний пульс всей записи. Доля лёгкого бега и темп на лёгком пульсе считаются так же; для несвязанной пробежки берётся граница из текущего плана. Одна и та же пробежка из Health Connect и из FIT учитывается один раз.

Цели сезона добавляются один раз при запуске. Заметка весеннего старта обновляется, только если в ней остался прежний текст по умолчанию; изменённые вручную цели не перезаписываются.

## Совместимость и безопасность

Код версии 22. Схема Room остаётся 7, миграция не требуется: новые поля шага хранятся в JSON тренировки и имеют значения по умолчанию. Формат отчёта 7, резервной копии 4, входящего плана 1. Версии до 0.3.19 отклоняют план с новыми полями, а шаги из резервной копии 0.3.19 с такими полями в них не отображаются: восстанавливать новую копию в старую версию не следует. Перед установкой рекомендуется сохранить резервную копию. Объявления зависимостей не менялись. Ключи, credentials и пользовательские данные в выпуск не включаются.
