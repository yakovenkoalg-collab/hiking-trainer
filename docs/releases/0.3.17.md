## Совместимость и безопасность

Код версии 20. Миграция Room 6→7 сохраняет историю и добавляет отдельную дату занятия, режим записи и источник пульса. Для старых записей новые сведения остаются неизвестными. Ключ подписи прежний; ключи, credentials и пользовательские данные не публикуются.
