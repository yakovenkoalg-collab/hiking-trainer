# Горная форма 0.3.23 · 19 октября 2026

- [Новое] Точный подсчёт пульса: для записей Garmin приложение сохраняет, сколько секунд пульс был на каждом значении, и показывает минуты выше границы и пиковый пульс, а не оценку по кругам или среднему.
- [Новое] «Засчитать по Garmin»: если к беговой тренировке привязана запись Garmin, дата, время и все этапы заполняются автоматически — остаётся оценить нагрузку и сохранить. Кнопка есть в тренировке и у связанной записи в «Тренировках Garmin»; окно открывается и сразу после привязки записи.
- [Исправление] Записи из FIT-файлов заканчивались в момент старта: Garmin ставит итоговую отметку на время начала. Теперь конец записи считается по длительности; при повторном импорте старые записи исправляются.
- [Исправление] Бег на дорожке из Health Connect распознаётся как бег.

Для уже загруженных пробежек точный подсчёт появится после обновления данных: «Тренировки Garmin → Обновить данные» для записей из Health Connect или повторный импорт FIT-файла. Связи с тренировками при этом сохраняются. План и расписание не меняются.
