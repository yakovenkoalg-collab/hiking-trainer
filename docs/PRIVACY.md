# Использование данных здоровья

«Горная форма» читает данные Health Connect только после явного разрешения пользователя:

- тренировки;
- пульс;
- сон;
- шаги;
- расстояние;
- набор высоты;
- вес.

Данные используются для личного плана, сводок и защиты от двойного учёта нагрузки. Пользователь может дополнительно выбрать локальный FIT-файл; он разбирается на устройстве официальной библиотекой Garmin FIT, а исходный файл не копируется в базу.

По умолчанию данные хранятся только в локальной базе приложения. Пользователь может явно выбрать общую папку через системный Android-проводник либо подключить Яндекс Диск OAuth-токеном и отдельно включить автообмен. Токен шифруется ключом Android Keystore и не входит в отчёты или резервные копии. Фото осанки в обмен не включаются.

Пользователь может отозвать разрешения в настройках Health Connect, отключить автообмен или отозвать доступ к общей папке в системных настройках Android.
