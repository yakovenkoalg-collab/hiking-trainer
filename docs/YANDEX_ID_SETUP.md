# Вход через Яндекс ID

Приложение использует официальный LoginSDK для Android 3.1.3. Веб-виджет мгновенного входа внутрь APK не встраивается: для нативного Android Яндекс предоставляет LoginSDK.

## Регистрация приложения

В кабинете [Яндекс OAuth](https://oauth.yandex.ru/client/new) создайте приложение со следующими параметрами:

- платформа: Android-приложение;
- package name: `ru.yakovenko.mountainform`;
- SHA-256 сертификата текущей личной подписи: `AE:CE:7D:0B:81:41:13:A6:9E:23:53:6E:64:C0:3E:6A:E1:CA:D9:F8:0B:EF:3E:6C:48:E8:B8:26:A6:1F:4F:B3`;
- единственное дополнительное право: «Доступ к папке приложения на Диске» (`cloud_api:disk.app_folder`).

Google Play URL для личного APK не используется. Если Яндекс допускает пустое значение, оставьте его незаполненным.

## Сборка

Полученный Client ID не является секретом. Для личной сборки он уже задан в `gradle.properties`; при необходимости его можно переопределить параметром Gradle:

```bash
./gradlew assembleRelease -PyandexClientId=CLIENT_ID
```

Без `yandexClientId` приложение собирается, но кнопка «Войти с Яндекс ID» отключена и объясняет причину. Client secret для LoginSDK не нужен и не должен попадать в проект. Обмен идёт внутри `app:/`; приложение не имеет доступа к остальному содержимому Яндекс Диска.

После смены сертификата подписи новый SHA-256 нужно добавить в настройках OAuth-приложения до установки APK. Токен пользователя хранится только в зашифрованном хранилище Android и удаляется командой «Отключить».
