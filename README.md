# Горная форма

Персональное Android-приложение для круглогодичной горной готовности: сила, аэробная база, работа под рюкзаком, устойчивость к спускам, core, осанка и восстановление.

## Принципы

- offline-first и без обязательного аккаунта;
- данные о здоровье остаются на телефоне;
- Garmin Connect передаёт доступные показатели через Health Connect;
- план можно корректировать через проверяемый импорт/экспорт;
- приложение предлагает изменения нагрузки, но не ставит диагнозы и не заменяет специалиста.

## Локальная сборка

Требования:

- JDK 17;
- Android SDK Platform 36;
- Android SDK Build Tools 35.0.0 или новее.

```bash
./gradlew testDebugUnitTest
./gradlew assembleDebug
./gradlew connectedDebugAndroidTest
```

Debug APK появится в `app/build/outputs/apk/debug/app-debug.apk`.

После первичной подготовки локальные JDK и Android SDK находятся в `.tooling/`. Полная проверка запускается через `scripts/verify.sh`, а оконный эмулятор — через `scripts/start-emulator.sh`.

## Текущая версия 0.3.8

Реализованы адаптивный экран «Сегодня» с устойчивой вёрсткой при увеличенном шрифте, единый блок готовности и ограничений, выделенная следующая тренировка, компактные действия core/осанки и корректировки плана, облегчённый календарь и прогресс, обзор занятия с постоянно доступной кнопкой запуска, режим тренировки по подходам/кругам/интервалам, быстрый результат одним нажатием, необязательные таймер и подробная форма, техника по запросу, звуковой и вибросигнал, учёт планового и фактического отдыха, безопасная пауза при боли, восстановление таймеров после возврата на экран, журнал веса/повторов/RPE/RIR/боли, локальный каталог с иллюстрациями, readiness-check, core/осанка, контрольная точка после трёх тренировок, входящие активности Garmin через Health Connect, импорт FIT/ZIP с зонами, Training Effect, нагрузкой, кругами и беговой динамикой, ручная связь факта с планом, общая папка SAF, вход в Яндекс ID через официальный LoginSDK, резервные копии, подробный preview нового плана, напоминания и обновление APK. Беговая цель отображается в «Прогрессе», а подробные пояснения, источники данных и резервные операции раскрываются по запросу и не мешают основному сценарию тренировки.

Рабочий цикл корректировки: приложение создаёт контрольную точку после трёх завершённых ключевых тренировок или раньше при боли → пользователь делится JSON-отчётом в чате → получает новый план → проверяет preview → подтверждает импорт. Приложение не заменяет план автоматически и поддерживает резерв будущих тренировок на 7–14 дней.

Локальный ARM64-эмулятор хранится в игнорируемой `.tooling/`; AVD называется `MountainFormApi35`.

Для личных обновлений используется один постоянный локальный ключ; ключ и пароли не хранятся в Git. Release APK по умолчанию проверяет `https://yakovenkoalg-collab.github.io/hiking-trainer/latest.json`; другой канал можно передать при сборке через `-PupdateManifestUrl=https://…/latest.json`.
